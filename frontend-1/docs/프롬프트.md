# 프로젝트 개요

이 문서는 React를 사용하여 프론트엔드 UI를 구현하기 위한 초기 프롬프트와 컨텍스트를 제공합니다. 이 프로젝트는 FastAPI로 구현된 백엔드와 통합됩니다.

## UI 설계도
- UI 설계도는 `frontend/docs/chat_ui_설계도.jpg`에 위치합니다. 이 설계도를 기반으로 프론트엔드 UI를 구현합니다.

## 폴더 구조
- **backend/**: FastAPI로 구현된 백엔드 코드가 위치합니다.
- **frontend/**: React로 구현된 프론트엔드 코드가 위치합니다.

## 작성 파일
- `frontend/docs/frontend_spec.md`: 프론트엔드 UI 구현을 위한 사양서입니다.

## Context7 MCP 사용 지침
본 프로젝트의 코드 생성, 리팩터링, 오류 수정, 라이브러리 사용법 확인 시 VS Code MCP Servers에 설치된 Context7 MCP를 사용합니다. 다음 라이브러리 또는 프레임워크를 사용할 때는 반드시 Context7 MCP로 최신 공식 문서와 코드 예제를 확인한 뒤 구현합니다.
- FastAPI
- React
- Vite
- Ollama

## 코드 작성 원칙
- 초보자도 이해하기 쉽게 코드를 작성합니다.
- 유지보수가 용이하게 코드를 clean한 코드로 작성합니다.
- 코드의 오류가 발생하지 않도록 스펙 작성 시 꼼꼼하게 검토합니다.
